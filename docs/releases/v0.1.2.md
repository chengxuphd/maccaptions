## MacCaptions 0.1.2 — optional LLM translation, live and local

### New: context-aware translation with a local or cloud LLM (optional, off by default)
Choose a **Translation** mode in the panel and set up the model with **Set**.

- **Apple** (default): on-device translation, as before.
- **Apple + LLM:** Apple's translation appears first; your model then improves each finished sentence, using earlier sentences, your topic notes and a glossary. If the model is slow, offline or replies with something that is not a translation, Apple's stays.
- **LLM:** the Chinese comes only from your model. A local model translates **while the sentence is being spoken**; a cloud service gets finished sentences. A sentence it cannot translate shows “—” and is saved in English.

**Local:** Ollama, LM Studio, llama.cpp server. **Cloud:** OpenRouter, Tinker (beta), OpenAI, DeepSeek, or any OpenAI-compatible server. API keys are stored in the macOS Keychain. With a cloud provider, sentence **text** is sent to that provider (never audio), and the app shows where it is going. Saved transcripts record which engine translated each sentence.

Ollama and llama.cpp (about 0.2–0.3 s per sentence), OpenRouter (about 0.6–1 s) and Tinker (about 1.2 s) were tested with real models on one M5 Pro; on our made-up test sentences the better models did clearly better than Apple on idioms and technical terms. LM Studio, OpenAI, DeepSeek and custom servers have not completed a real translation yet. Models still make mistakes and do not repair speech-recognition errors. With Ollama, a model's memory use grows during long use (a 9B reached about 20 GB).

### Also new
- **Live update** slider: how often the Chinese is updated while someone is speaking (Apple, or a local LLM).
- The panel's transcript **stays where you are while you read earlier lines** (it used to jump to the newest one), and opens at the newest line.

### Changed and fixed
- Recordings and transcripts are saved in **`~/Documents/MacCaptions/`** (before: `LiveCaptions`). Sessions from 0.1.0 / 0.1.1 are **moved there automatically** the first time you start captions, only when the old folder contains nothing but MacCaptions sessions and no `MacCaptions` folder exists yet; nothing is ever overwritten.
- Fixed: pressing **Quit** while captions were stopping could leave the app unable to quit.
- Finished sentences still waiting for a translation are now also saved when the Mac shuts down or you log out.

### Requirements
macOS **26.4 or later**, **Apple silicon**. LLM translation additionally needs a local model server or an account with a cloud provider.

### Install
1. Download **MacCaptions-0.1.2-macos-arm64.dmg** below (a **.zip** of the same app is also attached), open it, and drag **MacCaptions.app** onto **Applications**.
2. The app is ad-hoc signed and **not notarized**. First launch: right-click → **Open** → **Open** (or *System Settings → Privacy & Security → Open Anyway*), or run `xattr -dr com.apple.quarantine /Applications/MacCaptions.app`.
3. Click the menu bar item → **Start captions**; allow Microphone and System Audio Recording; install the English and Chinese (Simplified) translation languages if macOS asks. After updating from an earlier version, macOS may ask for these permissions again.

Full instructions: see the [README](https://github.com/chengxuphd/maccaptions#readme).

### Known limitations
English speech → Simplified Chinese only · live LLM translation only with local models · on a crowded or notched menu bar, macOS may hide the menu bar captions behind its overflow arrow (the floating window is not affected) · saved audio is 16 kHz mono · tested on one Mac · not notarized.
